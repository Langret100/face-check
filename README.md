# AI 표정 친구 v19 — FHD · 구도 복원 · 사람형 팔 자세 · 음성 구분

- **다람쥐 구도 복원**: v12/v17의 기존 높이·기준점·세로 화면 계산을 다람쥐에만 적용.
- **사람형 구도**: 얼굴 중심 상반신을 v18보다 확대하고 화면상 조금 아래로 이동. 손 움직임에 따른 자동 카메라 변경 없음.
- **사람형 기본 팔**: VRM 실제 뼈 위치를 이용해 편안한 내려놓은 자세로 만들고 그 상태를 추적의 기준 자세로 저장. 다람쥐 기존 팔 자세 유지.
- **FHD 렌더링**: `devicePixelRatio`를 반영하고 출력 버퍼를 가로 1920×1080 / 세로 1080×1920 이내로 제한. FPS 저하 시 강제로 70%까지 해상도를 낮추던 코드 삭제. 실제 디스플레이·CSS 표시 영역보다 픽셀을 더 만들지는 않음.
- **음성 구분**: 사람형 한국어 TTS는 설치된 여성형 음성을 우선 선택하고 부드러운 피치/속도로 재생, 음성 따라하기는 약한 피치 상승. 다람쥐는 빠르고 높은 카툰 음색. 플랫폼에 여성 음성이 없을 땐 기본 한국어 음성 사용.
- Web Worker 얼굴·팔 인식 및 실패 시 대체 경로, VRM 2종과 사용권 고지 유지.

## 검증 범위
JavaScript 구문 검사, VRM 파일 유지, ZIP 무결성 확인. 실제 카메라/마이크, TTS 목소리 선택, 라이브 팔 동작, GitHub Actions 빌드 및 실기기 60fps는 검증되지 않았습니다.

## 배포
GitHub 저장소에 ZIP 내용을 모두 반영하고 Pages Actions 배포. 기존 리포지토리에 남은 미사용 파일은 별도로 제거.


## v20 FPS / FHD 최적화
- FHD 렌더링 기준을 유지하며 FPS에 따른 해상도 축소를 도입하지 않습니다.
- 전 화면 WebGL 캔버스에 적용되던 CSS drop-shadow 후처리를 제거했습니다. 정보 패널의 backdrop-blur도 제거했습니다.
- 얼굴/표정의 메시·모프 연결을 모델 교체 시 단 한 번 구성합니다. 60fps 루프에서는 캐시된 연결만 갱신하며 임시 배열을 만들지 않습니다.
- 어깨/가슴 관절 계산의 임시 Quaternion과 Euler 생성을 공용 객체로 재사용합니다.
- Worker 추론 큐는 1프레임으로 제한하고, CPU 대체 경로에서는 얼굴 인식에 팔 인식이 밀리지 않도록 기한 초과량에 따라 공평하게 수행합니다.
- 화면 DPR이 변경되면 렌더링 버퍼를 갱신하며, FHD 한도를 넘어 GPU 부하가 커지지 않게 합니다.
- 이전 버전과 동일하게 브라우저에서 확인하지 않은 60fps는 보장하지 않습니다.
